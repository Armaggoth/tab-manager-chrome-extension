# Feature Specifications

This folder contains self-contained specifications for new, large features. Each specification has a stable sequential folder name: `specNNN`.

## Rules

- Create a new `specNNN` folder before implementing a large feature.
- Keep its decisions, requirements, implementation tasks, accessibility requirements, validation plan, and continuation point in that folder.
- Link the specification from [Documentation](../index.md) and the relevant roadmap item in [Development Progress](../guides/PROGRESS.md).
- Do not migrate or rewrite documentation for completed features. This convention applies to new large features going forward.
